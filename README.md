#Expense Tracker
A simple Python based Expense Tracker that helps the users to record and manage their daily expenses.

#Features
- Add new expenses
- View all recorded expenses
- View total expenses
- Simple menu-based interface
- Easy to use for beginners

#Technologies Used
- Python
- Python Lists
- User Input
- Conditional Statements
- Loops

#How to Run
1. Clone this repository.
2. Open the project in VS Code.
3. Run the following command:

```bash
python main.py
